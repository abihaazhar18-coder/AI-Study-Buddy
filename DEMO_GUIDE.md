# StudyMate AI – 3-minute demo script

Before you start, open `index.html` in Edge. If it already has data, click **Reset data** first.

| Time | Do | Say |
|---|---|---|
| 0:00 | Show the empty Dashboard. | "Students have many subjects, long chapters and clashing exams. StudyMate AI is one HTML file that works offline, with no install and no account." |
| 0:20 | Click **Load demo data**. | "Here are three subjects with exam dates. The stat cards show days left, average quiz score, planner progress and flashcards due today." |
| 0:40 | Go to **Notes**, click **Open** on *Photosynthesis basics*. | "The offline AI pulled out a summary, key concepts, definitions and bullet notes. It's all editable Markdown with a live preview, and it downloads as .md or .txt." |
| 1:05 | Paste a new paragraph, click **Generate notes**. | "Any text works, and you can also load a .txt or .md file." |
| 1:20 | Click **Make flashcards**, go to **Flashcards**, then **Start practice**, **Show answer**, **Good**. | "Definitions become term cards and key concepts become cloze cards. Spaced repetition schedules each card's next review." |
| 1:50 | Go to **Quiz**, click **Generate quiz**, answer a few, then **Submit**. | "We get multiple-choice cloze questions and true/false. Each answer shows the source sentence. Scores are saved per subject." |
| 2:20 | Go to **Planner**, click **Regenerate plan**, tick a session. | "The plan runs day by day until each exam. Sooner exams and weaker subjects get more time, and there's always a review day before the exam." |
| 2:40 | Toggle **Dark mode**, open **Settings**. | "There's an optional OpenAI-compatible API with automatic offline fallback. Data stays in the browser. It's MIT licensed." |
| 2:55 | Back to **Dashboard**. | "Organize, learn, practice, plan. That's StudyMate AI." |
